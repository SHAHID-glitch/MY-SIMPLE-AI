Gemini AI Assistant

Beautiful 3D AI Chat Application powered by Google Gemini 2.5 Flash

⚠️ Important Notice About GitHub Pages Deployment

This is a Flask-based backend application that requires a server to run. GitHub Pages only serves static HTML files and cannot run Python backend code. The AI chat functionality will not work when deployed to GitHub Pages.

✨ Features of This Application

  • 🎨 3D Animated UI with glassmorphism design
  • 🤖 Powered by Google Gemini 2.5 Flash AI
  • 💬 Real-time conversation with AI
  • 📱 Fully responsive design
  • 🎭 Beautiful message avatars and animations
  • ⚡ Session-based chat history

🚀 How to Run This Application Locally

  1. Clone this repository: git clone https://github.com/SHAHID-glitch/MY-SIMPLE-AI.git
  2. Navigate to the directory: cd MY-SIMPLE-AI
  3. Install dependencies: pip install -r requirements.txt
  4. Create a .env file and add your Google Gemini API key:
    GOOGLE_API_KEY=your_api_key_here
  5. Run the Flask server: python Backend.py
  6. Open your browser and visit: http://localhost:5000
